# 张小星图文视频生成器

这是一个基于 Python 和 PySide6 的 Windows 桌面工具，支持：

- 输入主题和每张图文案，选择图片风格后批量生成图片
- 导入本地图片，填写视频提示词后生成短视频
- 导入 Excel、XLSM 或 CSV，批量生成图片和视频
- 使用 APIB / APIMart 异步图片、视频和上传接口
- 动态获取账号可用的图片、视频、音频和文本模型
- 显示模型展示价、Token单价、Token用量和最近30天账单
- 将图片、视频和分镜文案生成剪映 6.0.1 可编辑草稿
- 生成抖音、快手、小红书、视频号、B站平台适配文案并辅助上传
- 没有 API Key 时使用本地演示模式测试完整流程

## 快速启动

双击：

`启动软件.bat`

启动脚本会检查依赖。如果缺少依赖，会自动执行：

```powershell
python -m pip install -r requirements.txt
```

也可以手动启动：

```powershell
cd "张小星图文视频生成器"
python app.py
```

## 首次配置

打开软件顶部的“配置”页面：

1. 填写 APIB / APIMart API Key。
2. Base URL 默认使用 `https://api.apib.ai/v1`。
3. 如果只想测试界面和流程，保持“演示模式”开启。
4. 需要正式出图时，关闭演示模式并点击“保存配置”。
5. 点击“测试连接”确认 API 可访问。

API Key 使用 Qt 本机设置保存，不会写入源码文件。

## 图文生成

1. 输入主题。
2. 在“每张图文案”中每行填写一张图的内容。
3. 选择图片风格、图片模型、质量、画面比例和清晰度。
4. 点击“一键生成全部图文”。
5. 在右侧预览结果，点击“打开文件”或“打开目录”查看原图。

默认图片比例为 `3:4`，适合小红书图文。抖音竖版视频可改用 `9:16`。

### 封面图生成

“图文生成”页面新增独立的封面图生成技能：

1. 填写封面主标题。
2. 可选填写封面副标题。
3. 选择图片风格、模型、质量和清晰度。
4. 点击“生成封面图”。

封面图固定使用 `3:4` 画布，并自动强调主标题、副标题、图标和手机端可读性。输出会保存到图文页面指定的输出路径下，生成结果会加入右侧预览区。

`gpt-image-2.5-flare` 支持质量选择：

- 低：`low`
- 中：`medium`
- 高：`high`
- 极高：`xhigh`
- 最高：`max`
- 自动：`auto`

其他图片模型不支持该质量参数时，质量选择会自动禁用，不会向接口发送 `quality` 字段。

“一键生成全部图文”现在会自动把封面图作为第一个任务生成，然后继续生成每一行图文。封面固定使用 `3:4`，页面图继续使用页面中选择的画面比例。

封面排版规则：

- 主标题是画面第一视觉中心。
- 主标题使用超大字号、粗重字体和高对比配色。
- 标题文字块占画面高度约 `45%` 至 `60%`。
- 主标题采用 2 到 3 行大字排版，单个汉字笔画粗重饱满。
- 超过 10 个汉字时自动拆分为多行，不缩小字号。
- 副标题字号明显小于主标题。
- 装饰元素不能抢走标题视觉重量。
- 主标题输入框右侧实时显示汉字计数，建议控制在 14 个汉字以内。
- 超过 14 个汉字时，生成前会提醒标题可能被模型缩小。

## 视频生成

1. 添加一张或多张参考图片。
2. 选择“每张图片各生成一条”或“多张图片合成一条”。
3. 填写视频提示词。
4. 选择视频模型、比例、清晰度和时长。
5. 点击“一键生成视频”。

真实模式会先上传本地图片，再把上传后的 URL 传给视频生成接口。生成完成后软件自动下载视频并创建缩略图。

默认视频模型为 `seedance-2.0-fast`。不同模型支持的时长和分辨率不同，软件会在提交前进行校验。

## 模型中心

顶部“模型中心”页面按四类显示模型：

- 图片模型
- 视频模型
- 音频模型
- 文本模型

软件优先调用：

`GET /v1/models?expand=category`

动态模型范围取决于当前 API Key 的权限和分组。接口不可用或未配置 API Key 时，显示内置文档清单作为回退。

模型中心支持按模型 ID 或能力标签搜索。双击图片或视频模型可以直接应用到对应生成页面。

模型中心还会调用公开价格接口：

`GET /api/pricing/model?model=模型ID`

配置 API Key 后还会调用：

`GET /v1/usage`
`GET /v1/balance`

用于显示最近30天的 Token 用量、消费金额和余额。图片、视频模型通常按张或按秒计费，显示价格不会转换成虚假的 Token 数量。

## 剪映草稿

“剪映草稿”页面支持：

- 上传图片或视频
- 载入本软件最近生成的图片和视频
- 每行填写一段字幕或分镜提示词
- 设置竖版、横版或方形画布
- 设置图片时长、视频使用时长和帧率
- 生成剪映草稿并自动启动剪映

默认草稿目录：

`%LOCALAPPDATA%\JianyingPro\User Data\Projects\com.lveditor.draft`

生成后，如果剪映已经打开，请重启剪映，再进入草稿列表查看“张小星草稿”。

当前草稿生成兼容剪映 6.0.1。剪映草稿是本地私有格式，升级剪映后如果格式变化，需要同步调整 `pyJianYingDraft` 版本或草稿模板。

## Hypit 视频引擎

软件新增独立的“Hypit视频”栏目。Hypit 作为本地 Node.js 视频工作流引擎运行，不替换现有图片、视频和剪映草稿功能。

### 简易模式

“Hypit视频”现在分为“简易模式”和“高级模式”。普通使用只需要留在简易模式：

简易模式采用从上到下的顺序执行布局：

1. 在第 1 步粘贴小红书、抖音、快手、视频号或 B站链接，或者选择本地视频，点击“一键分析并生成工程”。
2. 软件自动下载视频、读取时长和音轨、提取关键画面、识别镜头变化、转写口播并生成参考工程。
3. 在第 2 步填写真正创作目标和真正开头钩子。
4. 选择脚本改写模型、改写强度、去 AI 味、去商业促销、配音模型和音色。
5. 点击“按创作目标生成原创口播”。软件会重写口播、生成配音、重新识别字幕时间并创建新的可编辑工程。
6. 在第 3 步确认新口播后点击“生成原创成片”，完成后播放或打开工程。

第 1 步生成的参考工程只保留参考画面与参考音轨，不会自动采用第 2 步创作目标。只有执行“按创作目标生成原创口播”后，创作目标和钩子才会进入新脚本、新配音和新字幕。

抖音链接优先使用无头 Edge 打开真实页面并捕获播放器媒体地址，不依赖 yt-dlp 尚未实现的抖音签名接口。其他平台继续使用 Hypit 的 yt-dlp 下载能力。

真实模式会调用 APIB Whisper-1 和多模态模型，可能产生少量 API 费用。软件会在执行前明确询问确认。未配置 API Key 或处于演示模式时，仍会生成可编辑工程，但画面分析使用基础规则，不调用云端模型。

每次生成都建立在统一工作台：

`%LOCALAPPDATA%/ZhangXiaoxingGenerator/hypit_projects/张小星Hypit工作台/runs/`

每次任务创建独立子目录，不会覆盖之前的工程。最终成片位于该任务的 `output/final.mp4`。

第一阶段生成的工程只保留参考画面和参考音轨，不负责按创作目标重写口播。软件在参考工程完成后会把按钮显示为“导出参考画面”；如果参考视频没有音轨，会明确提示先执行“按创作目标生成原创口播”。原创口播完成后按钮才会变为“生成原创成片”。

“高级模式”保留原有项目、Runtime、Provider、Plan、Build、Status、导出和 Studio 控制，供后续复杂工作流和故障排查使用。

### 第二阶段：原创口播与配音

第一阶段工程生成后，简易模式会启用“2. 原创口播与配音”区域：

1. 选择“轻度改写”“中度改写”或“深度改写”。
2. 勾选“去 AI 味”和“去掉商业促销”。
3. 选择配音模型和音色。
4. 点击“生成原创口播版本”。

第二阶段会自动完成：

- 根据参考视频分析和口播转写重写原创脚本。
- 避免逐句照抄，减少机械排比和模板化表达。
- 按开关减少 AI 味与商业促销话术。
- 调用 APIB TTS 生成新配音。
- 再次转写新配音，获得字幕时间点。
- 保留参考视频画面，替换原口播和字幕。
- 生成新的可编辑 Hypit 工程，可继续打开 Studio 修改。

配音支持：

- 音色选择，默认 `nova`，同时提供 Shimmer、Coral、Sage、Alloy、Echo 等音色。
- 朗读风格：亲切科普、专业讲解、温暖治愈、有活力、强钩子、沉稳提醒。
- 情绪强度：自然、明显、强烈。
- 语速控制：`0.85` 到 `1.15`。
- 段间停顿：短、标准、长。
- 分段情绪：开头更有抓力，风险提醒更严肃，方法与步骤更清晰，结尾更舒缓。
- “试听当前音色和情感”按钮，可先试听短句再生成完整配音。

真实音色试听会调用一次 TTS，可能产生少量 API 费用；演示模式只生成静音占位。音色上传和声音克隆尚未启用。

演示模式不会调用付费 TTS，而是使用原音或静音作为占位，仅用于验证工程和渲染流程。真实模式会在执行前提示文本改写、TTS 和 Whisper 可能产生 API 费用。

## 爆款重构

“爆款重构”页面用于从小红书可见内容出发，围绕自己的参考内容生成原创图文。

采集方式：

- 手动粘贴小红书链接。
- 输入关键词搜索，读取当前可见结果。

两种方式都使用浏览器辅助打开小红书官方页面，只读取当前可见内容，不调用私有接口。首次使用需要扫码登录，软件会等待登录完成。

创作参考包：

- 参考内容：必须参考的事实、观点和护理要点。
- 产品或服务。
- 目标人群。
- 内容风格：
  - 小红书风格
  - 干货科普风
  - 简短吐槽爽文风
  - 极简高级质感风
  - 避坑对比测评风
  - 闺蜜碎碎念日记风
- 目标字数。
- 生图风格和文本模型。

生成结果包括：

- 原创标题和封面标题。
- 原创正文和标签。
- 分页脚本。
- 每页生图提示词。
- 视频提示词。

可以导出为 Excel，也可以直接发送到“图文生成”页面继续生成图片。原创内容必须围绕参考内容重新组织，不应直接复制原爆款。

鼠标悬停在内容风格下拉框上会显示当前风格的特点。页面底部“清空内容”按钮会清空采集结果、参考内容、原创文案和生图提示词。

## 发布中心

“发布中心”第一阶段的定位是一键准备、分发和确认发布，不依赖平台发布 API 审核。

支持平台：

- 抖音
- 快手
- 小红书
- 视频号
- B站

### 小红书优先流程

图文生成、视频生成和批量处理页面都提供“发送到发布中心”：

- 图文生成：发送当前全部生成图片，并带入主题和图片文案。
- 视频生成：发送当前全部生成视频，并带入视频主题和提示词。
- 批量处理：发送选中行；未选择行时发送全部行。图文和视频会自动拆成不同草稿，避免小红书混发。

发布中心的平台标签页全部启用，可直接切换到需要查看或发布的平台：

1. 在“小红书登录”区域点击“扫码登录小红书”。
2. 使用小红书 App 扫码。
3. 登录状态保存在 `%LOCALAPPDATA%/ZhangXiaoxingGenerator/browser_profiles/xiaohongshu`。
4. 点击“检测登录状态”确认登录。
5. 检查草稿标题、正文、标签和素材。
6. 点击“生成平台适配文案”，再点击“辅助上传”。
7. 软件打开官方发布页，自动上传素材并填写标题、正文和标签。
8. 最终发布必须由你在浏览器中检查后手动点击。

话题标签不会作为普通 `#文字` 塞进正文。软件会在小红书联想列表中选择完全匹配的话题项，写入真实 `tiptap-topic` 话题节点；没有匹配话题时保留普通文本。

软件不读取用户日常 Edge 的 Cookie，不保存账号密码，默认也不会自动点击最终发布。点击“清除登录状态”会删除独立浏览器配置。

定时发布说明：

- 自动化由 Playwright 直接控制 Chrome 或 Edge，不需要额外安装浏览器插件或扩展。
- 发布中心可以选择 Microsoft Edge 或 Google Chrome。
- 可勾选“定时发布”并选择日期时间；软件会开启小红书定时发布并写入指定时间。
- 软件不会点击最终发布，定时设置完成后由你检查页面并手动点击发布。
- 定时时间范围为当前时间后 1 小时到 14 天，最终时间以小红书页面校验为准。

每个平台会独立生成：

- 平台标题
- 平台简介或正文
- 平台标签
- 长度校验结果
- 素材格式校验结果

操作流程：

1. 填写统一标题、简介和标签。
2. 上传图片、视频，或载入本软件最近生成的结果。
3. 点击“生成平台适配文案”。
4. 切换到需要使用的平台标签页。
5. 检查每个平台标签页中的提示。
6. 点击“复制全部文案”或“打开官方发布页”。
7. 首次使用时，在打开的 Edge 窗口登录对应平台。
8. 点击“辅助上传”，软件会尝试加载文件并填写标题、简介。
9. 浏览器中的最终发布按钮必须由你手动点击。

辅助上传使用本机 Microsoft Edge 和 Playwright，每个平台使用独立浏览器配置目录。软件不会：

- 自动点击最终发布
- 处理或绕过验证码
- 绕过平台风控
- 保证平台网页选择器永久有效

平台网页结构变化时，辅助上传可能只能完成部分填写，此时仍可使用剪贴板和官方发布页手动完成。

### 抖音发布

发布中心的抖音标签页已按小红书相同的流程和布局配置：

- 独立抖音登录状态，支持扫码登录、检测登录和清除登录。
- 可选择 Microsoft Edge 或 Google Chrome 自动化浏览器。
- 支持抖音视频和图文上传。
- 自动填写作品标题、作品描述和话题标签。
- 支持读取并填写定时发布时间。
- 支持从抖音官方“推荐、热门榜、飙升榜、原创榜、收藏”等音乐列表中选择音乐。
- 依旧由用户检查预览后手动点击最终发布。

抖音发布页选择器和页面结构可能随平台更新变化。如果软件只能打开页面但无法完成填写，请保留页面并手动补充。

抖音音乐选择说明：

- 仅视频发布支持音乐选择。
- 可设置榜单、歌曲关键词和第几首。
- 填写关键词时，优先匹配歌曲名称或作者。
- 未填写关键词时，自动选择所选榜单的第 N 首。
- 软件只在抖音官方音乐面板中点击“使用”，不会下载或重新上传音乐。
- 找不到匹配歌曲时会中止并保留浏览器页面，由用户手动选择。

## 批量发布素材导入

发布中心支持批量导入已经生成好的图片和视频，不需要重新生成素材。

文件夹导入规则：

```text
发布素材/
  笔记01/
    01_封面.png
    02_内容.png
    03_内容.png
  笔记02/
    成片.mp4
    封面.jpg
```

- 一个包含图片的文件夹会生成一个图文发布包。
- 第一张自然排序图片作为默认封面。
- 包含视频的文件夹会按视频生成视频发布包。
- 图片或视频散落在多个子目录时，每个素材目录会单独生成发布包。

推荐流程是先点击“导入素材文件夹”，再点击“导入发布 Excel”。Excel 会按照有效行顺序，依次补充当前发布包列表中的标题、内容和标签。

Excel 支持以下列：

| 列名 | 说明 |
| --- | --- |
| 标题 | 小红书标题 |
| 内容 | 小红书正文，可包含多行 |
| 标签 | 空格或逗号分隔 |
| 定时发布时间 | 推荐 `YYYY/M/D H:mm`，也支持常见日期格式 |

示例：

```text
标题    内容                        标签                  定时发布时间
标题01  第一行正文内容              肛周护理 健康科普      2026/10/1 10:00
标题02  第二行正文内容              久坐党 健康生活        2026/10/1 20:00
```

- 定时发布时间默认按 `yyyy/M/d H:mm` 显示，例如 `2026/10/1 10:00`。
- 同时兼容 `2026-10-01 10:00`、带秒格式以及 Excel 日期单元格。
- 选择发布包或生成平台适配文案时，Excel 定时时间会自动填入小红书定时发布时间，并自动勾选“定时发布”。
- Excel 第一行有效数据对应发布包列表第一项。
- Excel 第二行有效数据对应发布包列表第二项，以此类推。
- 空行会自动跳过。
- Excel 行数与发布包数量不一致时，软件会提示确认后再匹配。
- 导入时会自动执行素材存在性、格式、标题长度、图片数量、视频数量、标签数量和时间格式校验。
- 发布包状态显示“需修正”时，将鼠标停留在该行或状态文字上，会显示修正原因和对应修正方法。

发布包加入列表后，可逐条选择、修改标题正文标签，再点击“批量准备小红书”。第一版默认只上传和填写内容，停在最终发布按钮前，由你逐条确认发布。

## Excel 批量生成

点击“下载导入模板”可以生成标准 Excel 模板。

支持的列名：

| 列名 | 说明 |
| --- | --- |
| 主题 | 视频或图文主题 |
| 每张图文案 | 每张图的主要内容 |
| 风格 | 可选，留空使用批量页面选择的风格 |
| 生图提示词 | 可包含图1、图2、图3、图4等分段提示 |
| 视频提示词 | 可选，留空时根据主题和图文案自动生成 |
| 标签关键词 | 可选，用于记录标签 |

现有素材库可直接导入：

`肛周健康科普素材库_60条_含生图提示词.csv`

该文件中的“生图提示词”会自动拆分成4个独立生图任务，导入后应显示60行内容。

批量流程：

1. 导入 Excel 或 CSV。
2. 选择统一风格、图片模型和视频模型。
3. 点击“批量生成图片”。
4. 图片全部完成后，选择视频生成方式。
5. 点击“批量生成视频”。
6. 在输出目录中查看图片、视频、缩略图和运行日志。

批量生成图片时，每一行数据会自动增加一个独立封面图任务：

批量内页图片与图文生成页面使用同一套生图规则，并强制要求所有可见文字使用简体中文，禁止英文单词、英文字母、拼音和英文水印。

- 封面标题从该行主题自动提炼。
- 标题中的逗号、问号等会拆分为主标题和副标题。
- 主标题最多保留约 14 个汉字。
- 封面固定使用 `3:4` 画布，并应用大字封面模板。
- 输出顺序为：`00_封面`、`01_image`、`02_image` 等。

### 批量发布流程

批量处理页面保留“发送到发布中心”，不再提供批量排队发布和停止发布队列。

1. 批量图片或视频生成完成后，选择需要发布的行；未选择时使用全部行。
2. 点击“发送到发布中心”。
3. 软件会把每条数据拆成独立发布包，图文和视频不会混在同一条笔记。
4. 在发布中心继续导入 Excel、检查定时时间并执行“批量准备小红书”。
5. 最终发布仍由用户检查后在平台页面手动确认。

## 图文参考图

图文生成支持上传参考图，用于辅助图片模型保持产品、人物或背景的一致性。

- 支持格式：JPG、JPEG、PNG、WEBP。
- 单张参考图不能超过 10MB。
- 上传数量会按当前图片模型限制，超限图片不会加入列表。
- `不选择`：只使用文字提示词，不附加参考图说明。
- `图中产品`：参考产品外观、颜色、结构和材质。
- `图中人物`：参考人物外貌、服装、姿态和气质。
- `图中背景`：参考背景结构、光线、配色和氛围。
- `自定义：图1、图2...`：可点击“生成图1、图2描述模板”，分别描述每张参考图。

当前软件采用的主要参考图上限：

| 模型 | 参考图上限 |
| --- | ---: |
| GPT Image / GPT-4o Image | 5 |
| Gemini 3 Pro Image | 14 |
| 其他 Gemini 图片模型 | 5 |
| Seedream | 10 |
| Qwen Image | 3 |
| Z-Image Turbo | 不支持参考图 |

## 演示模式

## 输出目录

默认输出根目录：

`张小星图文视频生成器/output`

图文生成、视频生成、批量处理三个页面都提供独立输出路径：

- 图文生成：`output/images`
- 视频生成：`output/videos`
- 批量处理：`output/batch`

可以点击各页面的“输出路径”按钮重新指定目录。选择后会保存在本机配置中，下次启动继续使用。

每次任务仍会在指定目录下创建带时间戳的子目录，原始文件和中间文件都会保留。

生成接口返回的远程图片和视频 URL 可能有时效，软件会立即下载结果，不依赖远程链接长期保存。
